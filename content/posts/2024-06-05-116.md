最近在简单学习一些Node JS的用法，使用了Express框架来搭建基础的页面。但在遇到一个处理excel表格的需求时，使用推荐的excel-parser组件解析文件时，遇到error: command failed 无提示错误。一番搜索也没有找到解决方案，最终研究一下发现原因，特在此记录一下解决流程。

最初的时候，怀疑是在本地Mac环境搭建与Linux下不符，于是把代码上传到服务器上部署，发现会报同样的错误。然后查看发现是命令无法找到，于是修改了excel-parser的配置文件，将python解释器指向绝对地址，依然没有解决问题。

最后突然发现，excel-parser是依赖于python的excel解析器，其本身需要安装[xlrd](https://github.com/leftshifters/excel-parser/wiki/Package-installation)插件,于是下载https://pypi.python.org/pypi/xlrd的安装包，解压后，在目录下执行

> sudo python setup.py install

安装完成后，问题解决！
